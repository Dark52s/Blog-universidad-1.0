Manejo de CSS

Introducción

CSS (Cascading Style Sheets) es un lenguaje especializado en estilizar los documentos HTML y XML, basicamente, le dice al navegador como debe verse una pagina. Es el segundo pilar de las tecnologias web junto a JavaScript y al ya mencionado HTML. En este post desarrollaremos todolo necesario para empezar a usar CSS, selectores, propiedades y valor.
