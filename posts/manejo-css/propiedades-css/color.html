color

Descripción

La propiedad color define el color del texto de un elemento. Es una de las propiedades más utilizadas en CSS y permite especificar el color del contenido textual.

Valores

Puede tomar valores en formato hexadecimal (#FF0000), nombres de colores (red, blue, green), rgb() (rgb(255, 0, 0)), rgba() (rgba(255, 0, 0, 0.5)), hsl() o la palabra clave inherit para heredar del elemento padre.

Ejemplo

.texto-destacado {
    color: #0ceca5;
}

.texto-alternativo {
    color: rgb(255, 165, 0);
}
