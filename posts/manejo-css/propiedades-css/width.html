width

Descripción

La propiedad width establece el ancho de un elemento. Define la anchura del área de contenido del elemento, sin incluir el relleno, borde o margen.

Valores

Se puede especificar en pixels (300px), porcentaje (50%), ems, o usar auto para que el navegador calcule automáticamente el ancho según el contenido disponible.

Ejemplo

.contenedor {
    width: 100%;
}

.tarjeta {
    width: 300px;
}

.imagen {
    width: 50%;
}
