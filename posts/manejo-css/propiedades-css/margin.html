margin

Descripción

La propiedad margin establece el margen externo de un elemento, creando espacio entre el borde del elemento y los elementos circundantes. Es fundamental para el diseño y espaciado entre componentes.

Valores

Se puede expresar en pixels (10px), ems, porcentajes, o usando auto para centrar elementos. Se pueden especificar uno, dos o cuatro valores para diferentes lados.

Ejemplo

.contenedor {
    margin: 20px;
}

.centrado {
    margin: 0 auto;
}

.esquinas {
    margin-top: 10px;
    margin-bottom: 10px;
    margin-left: 20px;
    margin-right: 20px;
}
