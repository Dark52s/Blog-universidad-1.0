display

Descripción

La propiedad display define el tipo de caja que se genera para un elemento. Es una de las propiedades más importantes en CSS para controlar el diseño y layout de la página.

Valores

Los valores más comunes son: block (elemento en bloque), inline (en línea), inline-block (mezcla), flex (flexbox), grid (grid layout), none (ocultar elemento), y los valores table para emulate tablas.

Ejemplo

.bloque {
    display: block;
}

.en-linea {
    display: inline;
}

.centrado {
    display: flex;
    justify-content: center;
    align-items: center;
}

.oculto {
    display: none;
}
