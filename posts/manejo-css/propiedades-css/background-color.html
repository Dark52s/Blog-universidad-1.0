background-color

Descripción

La propiedad background-color establece el color de fondo de un elemento. El fondo se aplica detrás de todo el contenido del elemento, incluyendo el relleno y el borde.

Valores

Acepta los mismos formatos que la propiedad color: hexadecimal, nombres de colores, rgb(), rgba(), hsl(), o el valor transparent para hacer el fondo transparente.

Ejemplo

.card {
    background-color: #303030;
    padding: 20px;
}

.boton {
    background-color: #0ceca5;
    color: #121212;
}
