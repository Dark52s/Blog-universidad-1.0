font-family

Descripción

La propiedad font-family define la familia de fuente que se utilizará para el texto. Permite especificar una o varias fuentes como alternativa si la principal no está disponible.

Valores

Se especifica el nombre de la fuente (Arial, Open Sans, Times New Roman) y se puede añadir una lista separada por comas de fuentes alternativas, terminando con una familia genérica como serif, sans-serif, monospace, cursive o fantasy.

Ejemplo

.texto-principal {
    font-family: 'Open Sans', sans-serif;
}

.codigo {
    font-family: 'Courier New', monospace;
}

.titulo {
    font-family: Georgia, serif;
}
