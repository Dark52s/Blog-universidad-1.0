height

Descripción

La propiedad height establece la altura de un elemento. Define la altura del área de contenido del elemento, sin incluir el relleno, borde o margen.

Valores

Se puede especificar en pixels (200px), porcentaje, ems, o usar auto para que la altura se ajuste automáticamente al contenido del elemento.

Ejemplo

.banner {
    height: 400px;
}

.avatar {
    height: 150px;
}

.espacio {
    height: 50%;
}
