text-align

Descripción

La propiedad text-align define la alineación horizontal del texto dentro de un elemento. Es fundamental para controlar la presentación y legibilidad del contenido textual.

Valores

Los valores disponibles son: left (alineado a la izquierda), right (a la derecha), center (centrado), justify (justificado, espaciado uniforme) y start/end para dirección de texto.

Ejemplo

.centrado {
    text-align: center;
}

.derecha {
    text-align: right;
}

.justificado {
    text-align: justify;
}
