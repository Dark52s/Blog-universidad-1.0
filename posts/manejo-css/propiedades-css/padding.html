padding

Descripción

La propiedad padding define el espacio de relleno interno entre el contenido de un elemento y su borde. A diferencia del margen, el relleno forma parte del elemento y afecta su fondo.

Valores

Se puede expresar en pixels (15px), ems, porcentajes, y al igual que margin se pueden usar uno, dos o cuatro valores para diferentes lados.

Ejemplo

.boton {
    padding: 10px 20px;
}

.card {
    padding: 20px;
}

.celda {
    padding-top: 5px;
    padding-bottom: 5px;
    padding-left: 10px;
    padding-right: 10px;
}
