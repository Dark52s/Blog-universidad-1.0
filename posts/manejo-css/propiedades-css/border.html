border

Descripción

La propiedad border define el borde de un elemento. Es una propiedad shorthand que combina el ancho, estilo y color del borde en una sola declaración.

Valores

Requiere tres valores: el ancho del borde (en px), el estilo (solid, dashed, dotted, double, none) y el color. También se puede usar la palabra clave inherit.

Ejemplo

.tarjeta {
    border: 2px solid #0ceca5;
}

.punteado {
    border: 3px dotted red;
}

.sin-borde {
    border: none;
}
