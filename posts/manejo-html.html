El lenguje HTML

¿Que es HTML?:

HTML (HyperText Markup Language) es el lenguaje de marcado estándar utilizado para definir la estructura y el contenido de las páginas web mediante un sistema de etiquetas que actúan como el esqueleto del sitio. Estas etiquetas organizan elementos como encabezados, párrafos, enlaces e imágenes,permitiendo que los navegadores interpreten y presenten la información de forma jerárquica y legible.

Que es una etiqueta HTML?

Las etiquetas son palabras clave encerradas entre < y > que le dan instrucciones al navegador de como mostrar el cPtemas de codigo para pagina estilo visual studio code open sourceetición ontenido de la pagina, ejemplo: <p>, <h1>, <div>, etc. Se usan en pares (etiqueta de apertura y cierre) para "envolver" el contenido.

Atributos de una etiqueta HTML

Las etiquetas pueden llevar atributos, que proporcionan información adicional sobre el elemento. Siempre van dentro de la etiqueta de apertura. Existen atributos especificos para cada etiqueta como tambien atributos globales que pueden ser utilizados con cualquier etiqueta, entre estos encontramos:

  • id Es un identificador único. Como un número de identificación (DNI/Cédula); no debería haber dos elementos con el mismo id en una página. Se usa mucho para aplicar estilos específicos o anclas de navegación.

  • class: Es un identificador grupal normalmente utilizado para aplicarles estilos con CSS.

  • style: Permite escribir código CSS directamente dentro de la etiqueta.

  • title: Muestra un pequeño cuadro de texto (tooltip) cuando dejas el cursor encima del elemento.

  • lang: Indica el idioma del contenido de ese elemento (muy importante para el SEO y los lectores de pantalla).

  • hidden: Un atributo booleano que, si está presente, oculta el elemento de la vista.

Estrucura de un documento HTML

La estructura básica de un documento HTML5 comienza con <!DOCTYPE HTML> para indicar que es un documento HTML, ademas, permite elegir la version que es utilizara, seguida de la etiqueta raíz <html> que indica donde comienza y termina el codigo HTML. La siguiente etiquea es <head>(metadatos, título, enlaces a estilos) por ultimo <body> (contenido visible como texto, imágenes y enlaces). Es esencial para la correcta visualización en navegadores. 

 <!DOCTYPE html>
<html>
<head>
    <!-- Metadatos de la pagina -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Titulo de la pagina</title>
</head>
<body>
    <!-- Estructura de la pagina -->
</body>
</html>

Lista de Etiquetas

  • <html>: Engloba todo el documento e indica al navegador cual es el codigo html. Tiene su respectiva etiqueta de cierre, ademas, posee el atributo xmlnspara especificar el namespace XML del documento, indicando que el documento sigue las especificaciones XHTML. Normalmente se utiliza tambien el atributo <lang> para indicar el idioma de la pagina.

    <html lang="es">
  <head>
    <title>Mi sitio</title> 
  </head>
  <body>Hola</body>
</html>

  • <head>: Es un contenedor esencial situado al inicio del documento, justo antes del body. Este se utiliza para indicar informacion de la pagina como su nombre, idioma o guardar metadatos en general. Tiene su eqtiqueta de cierre.

    <head>
  <meta charset="UTF-8">
  <title>Mi sitio</title>
</head>

  • <body>: Funciona como el contenedor principal de todo el contenido visible de una página web. 

    <body>
  <h1>Bienvenido</h1>
</body>

  • <a>: Utilizado para crear hipervínculos, normalmente se utiliza para vincular el documento style.css. No necesita etiqueta de cierre

    <a href="https://example.com">Enlace</a>

  • <table>: Define una tabla para organizar datos estructurados.

    <table>
  <tr><td>Dato</td></tr>
</table>

  • <input>: es el elemento principal para crear campos interactivos en formularios.

    <input type="text" name="nombre">

  • <legend>: Se utiliza para proporcionar un título o descripción a un grupo de campos dentro de un elemento.

    <fieldset>
  <legend>Datos</legend>
</fieldset>

  • <iframe>: Permite incrustar un documento externo (otra página web, video, mapa o widget).

    <iframe src="https://www.example.com" width="300" height="200"></iframe>

  • <fieldset>: Agrupa elementos relacionados dentro de un formulario, creando visualmente un borde contenedor que mejora la estructura, organización y accesibilidad.

    <fieldset>
  <legend>Perfil</legend>
  <input type="text" name="email">
</fieldset>

  • <textarea>: Crea un campo de entrada de texto de varias líneas.

    <textarea name="comentario"></textarea>

  • <select>: Crea un menú desplegable para seleccionar una o varias opciones definidas por etiquetas.

    <select name="pais">
  <option value="ar">Argentina</option>
</select>

  • <option>: Se utiliza principalmente en formularios para recopilar datos, enviando el atributo value de la opción seleccionada al servidor.

    <option value="ar">Argentina</option>

  • <title>: Crea un titulo para la pagina html.

    <title>Mi página</title>

  • <p>: Define que lo que esta adentro de el sera un solo parrafo.

    <p>Este es un párrafo.</p>

  • <td>:Define una celda estándar dentro de una tabla que contiene datos.

    <td>Celda</td>

  • <button>: Crea botones clickeables para formularios, acciones en la página (JavaScript) o navegación.

    <button type="button">Click</button>

  • <table>:Define el inicio y fin de la tabla.

    <table>
  <tr><td>Fila</td></tr>
</table>

  • <style>: Permite incrustar código CSS directamente dentro de un archivo HTML.

    <style>
  body { color: blue; }
</style>

  • <br>: Se utiliza para insertar un salto de línea en el texto.

    <br>

  • <ol>: Define una lista ordenada (ordered list), numerada o alfabéticamente ordenada.

    <ol>
  <li>Elemento</li>
</ol>

  • <th>: Define una celda de encabezado en una tabla.

    <th>Encabezado</th>

  • <div>: Es un contenedor genérico de nivel de bloque utilizado para agrupar elementos, estructurar el diseño (layout) y aplicar estilos CSS o manipulación con JavaScript.

    <div class="contenedor">Contenido</div>

  • <img>: Se utiliza para incrustar imágenes en una página web. requiere dos atributos básicos obligatorios para funcionar correctamente y cumplir con la accesibilidad: src (fuente), que especifica la ruta o URL de la imagen, y alt (texto alternativo), que describe la imagen si no carga o para lectores de pantalla. 

    <img src="img/foto.jpg" alt="Foto">

  • <script>: Se utiliza para insertar código de programación, principalmente JavaScript. El más esencial es src (URL del archivo externo), junto con type (tipo de script).Es obigatorio usar una etiqueta de cierre al usar script.

    <script src="app.js"></script>

  • <hr>: Representa una ruptura temática entre párrafos o secciones.No requiere de atributos basicos ni de una etiqueta de cierre

    <hr>

  • <li>: Se utiliza para organizar contenidos, mostrando viñetas por defecto en listas no ordenadas o números/letras en las ordenadas. Su etiqueta de cierre. No requiere atributos unicos para funcionar.Esta tiene su atributo de cierre(es recomendable usarlo para tener el codigo mas ordenado). 

    <li>Elemento de lista</li>

  • <tr>: Se utiliza para definir una fila horizontal de celdas dentro de una tabla. Sus atributos básicos principales son class (para estilos CSS) y tambien id (para identificación única).Esta tambien requiere un atributo de cierre.

    <tr><td>Fila</td></tr>

  • <form>: Crea secciones interactivas para recopilar y enviar datos del usuario a un servidor,sus atributos son action (URL de destino), method(GET o POST para el método de envío).Esta tambien requiere un atributo de cierre.

    <form action="/submit" method="post"></form>

  • <label>: Define un texto descriptivo para elementos de formulario, mejorando la accesibilidad y la experiencia de usuario Sus atributos básicos son for (vincula el ID del input) y soporta atributos globales como id y class.Esta requiere una etiqueta de cierre 

    <label for="nombre">Nombre:</label>
