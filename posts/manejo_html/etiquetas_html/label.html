<label>

La etiqueta <label> define una etiqueta para un elemento de formulario. 

<label for="email">Correo electrónico:</label>
<input type="email" id="email" name="email">

Esta etiqueta acepta atributos específicos.

Atributo Descripción Ejemplo
for Asocia la etiqueta con un elemento de formulario por su id for="email"
form Asocia la etiqueta con un formulario por su id form="miFormulario"
accesskey Tecla de acceso rápido accesskey="c"
