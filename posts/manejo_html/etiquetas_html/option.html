<option>

La etiqueta <option> define una opción dentro de un elemento <select>. 

<option value="es" selected>España</option>

Esta etiqueta acepta atributos específicos.

Atributo Descripción Ejemplo
value Valor que se envía con el formulario value="es"
label Texto mostrado para la opción (si es diferente al contenido) label="España"
selected Opción seleccionada por defecto selected
disabled Desactiva la opción disabled
