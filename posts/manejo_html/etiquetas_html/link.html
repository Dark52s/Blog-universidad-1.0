<link>

La etiqueta <link> define la relación entre el documento y un recurso externo. Se usa principalmente para enlazar hojas de estilo CSS. 

<link rel="stylesheet" href="style.css" type="text/css">
Atributo Descripción Ejemplo
rel Relación del recurso (stylesheet, icon, etc.) <link rel="stylesheet"
href Ruta al recurso externo href="style.css"
type Tipo MIME del recurso type="text/css"
