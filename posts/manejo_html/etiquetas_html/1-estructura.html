1. Estructura del Documento

<html>

La etiqueta <html> es la etiqueta raíz que envuelve todo el documento HTML. Es el contenedor principal y acepta atributos como lang para especificar el idioma. 

<html lang="es">
  <head>...</head>
  <body>...</body>
</html>
Atributo Descripción Ejemplo
lang Especifica el idioma del documento (importante para SEO y lectores de pantalla) lang="es"
xmlns Define el namespace XML del documento (para XHTML) xmlns="http://www.w3.org/1999/xhtml"

<head>

La etiqueta <head> contiene metadatos e información sobre el documento que no es visible para el usuario, como el título de la página, enlaces a hojas de estilo, scripts y metadatos. 

<head>
  <meta charset="UTF-8">
  <title>Mi sitio</title>
  <link rel="stylesheet" href="style.css">
</head>

<body>

La etiqueta <body> contiene todo el contenido visible de la página: texto, imágenes, enlaces, tablas, formularios, etc. 

<body>
  <h1>Bienvenido</h1>
  <p>Este es el contenido visible</p>
</body>
