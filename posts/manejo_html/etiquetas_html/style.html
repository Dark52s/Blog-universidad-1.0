<style>

La etiqueta <style> define estilos CSS directamente en el documento HTML. 

<style media="screen">
  body { color: blue; }
</style>

Esta etiqueta acepta atributos específicos.

Atributo Descripción Ejemplo
media Medio al que se aplican los estilos (screen, print, all) media="screen"
type Tipo de contenido (text/css) type="text/css"
title Título del conjunto de estilos title="Estilos principales"
disabled Desactiva los estilos disabled
