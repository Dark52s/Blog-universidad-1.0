7. Multimedia y Recursos Embebidos

<img>

La etiqueta <img> inserta una imagen en el documento. Es una etiqueta vacía. 

<img src="foto.jpg" alt="Descripción de la imagen" width="300">
Atributo Descripción Ejemplo
src Ruta o URL de la imagen src="img/foto.jpg"
alt Texto alternativo (accesibilidad) alt="Logo"
width Ancho de la imagen width="300"

<iframe>

La etiqueta <iframe> embebe una página HTML externa dentro de la actual. 

<iframe src="https://example.com" width="500" height="300" allowfullscreen></iframe>

<script>

La etiqueta <script> inserta o define código JavaScript en el documento. 

<script src="app.js" defer></script>

<style>

La etiqueta <style> define estilos CSS directamente en el documento HTML. 

<style media="screen">
  body { color: blue; }
</style>
