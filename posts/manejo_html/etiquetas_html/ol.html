<ol>

La etiqueta <ol> define una lista ordenada (con números o letras). 

<ol type="1">
  <li>Primer elemento</li>
  <li>Segundo elemento</li>
</ol>
Atributo Descripción Ejemplo
type Estilo de numeración (1, A, a, I, i) type="A"
start Número inicial start="5"
