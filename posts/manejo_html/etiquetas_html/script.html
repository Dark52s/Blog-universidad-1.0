<script>

La etiqueta <script> inserta o define código JavaScript en el documento. 

<script src="app.js" defer></script>

Esta etiqueta acepta atributos específicos.

Atributo Descripción Ejemplo
src Ruta al archivo JavaScript externo src="app.js"
type Tipo de script (text/javascript, module) type="text/javascript"
defer El script se ejecuta después de parsear el HTML defer
async El script se ejecuta de forma asíncrona async
charset Codificación de caracteres del script charset="UTF-8"
crossorigin Permite scripts de otros dominios (anonymous, use-credentials) crossorigin="anonymous"
