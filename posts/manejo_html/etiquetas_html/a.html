<a>

La etiqueta <a> (ancla) crea enlaces a otras páginas, archivos o ubicaciones dentro de la misma página. Aunque casi siempre se utiliza exclusivamente para crear enlaces a otras paginas o a archivos de descarga. Esta necesita etiqueta de cierre.

<a href="https://example.com" target="_blank">Visita Example</a>
Atributo Descripción Ejemplo
href permite seleccionar la URL de destino del enlace <a href="https://www.link-de-la-pagina.com">
target Para elegir donde se abre el enlace. Los valores que acepta son:
  • _blank: Abre en otra pestaña.
  • _self: Abre en la misma pestaña (predeterminado)
  • _parent: Abre el link en el marco padre
  • _top: Abre el link en todo el cuerpo de la ventana.
 <a target="_blank">
title Tooltip que aparece al pasar el cursor title="Más info"
download Para crear enlaces de descarga de archivos. <a href="ruta-del-archivo" download="nombre del archivo">
