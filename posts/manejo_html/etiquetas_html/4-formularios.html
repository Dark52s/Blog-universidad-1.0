4. Elementos de Formulario

<form>

La etiqueta <form> define un formulario interactivo que recopila datos del usuario. 

<form action="/submit" method="post">
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre">
  <button type="submit">Enviar</button>
</form>
Atributo Descripción Ejemplo
action URL donde se envían los datos del formulario action="/submit"
method Método HTTP (GET o POST) method="post"

<label>

La etiqueta <label> define una etiqueta para un elemento de formulario. 

<label for="email">Correo electrónico:</label>
<input type="email" id="email" name="email">

<input>

La etiqueta <input> define un campo de entrada de datos. 

<input type="text" name="nombre" placeholder="Tu nombre" required>
Atributo Descripción Ejemplo
type Tipo de campo (text, email, password, number, date, checkbox, radio) type="email"
name Nombre del campo para el envío name="email"
placeholder Texto de ejemplo dentro del campo placeholder="ejemplo@correo.com"
required Campo obligatorio required

<select>

La etiqueta <select> define un desplegable (lista de opciones). 

<select name="pais">
  <option value="ve">Venezuela</option>
  <option value="co" selected>Colombia</option>
</select>

<option>

La etiqueta <option> define una opción dentro de un elemento <select>. 

<option value="es" selected>España</option>

<textarea>

La etiqueta <textarea> define un área de texto multilínea. 

<textarea name="comentario" rows="4" cols="50"></textarea>

<button>

La etiqueta <button> define un botón clicable. 

<button type="submit">Enviar formulario</button>

<fieldset>

La etiqueta <fieldset> agrupa varios controles y etiquetas dentro de un formulario.

<legend>

La etiqueta <legend> define un título para el elemento <fieldset>.
