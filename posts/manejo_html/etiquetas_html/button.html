<button>

La etiqueta <button> define un botón clicable.

Atributo Descripción Ejemplo
type Tipo de botón: submit, reset, button type="submit"
name Nombre del botón para el formulario name="enviar"
value Valor inicial del botón value="Click aquí"
disabled Desactiva el botón disabled
form Asocia el botón con un formulario por su id form="miFormulario"
autofocus El botón obtiene foco al cargar la página autofocus
