<textarea>

La etiqueta <textarea> define un área de texto multilínea. 

<textarea name="comentario" rows="4" cols="50"></textarea>

Esta etiqueta acepta atributos específicos.

Atributo Descripción Ejemplo
rows Número de filas visibles rows="4"
cols Número de columnas visibles cols="50"
name Nombre del campo para el envío name="mensaje"
placeholder Texto de ejemplo dentro del campo placeholder="Escribe tu mensaje"
required Campo obligatorio required
readonly Campo de solo lectura readonly
disabled Desactiva el campo disabled
maxlength Máximo número de caracteres maxlength="500"
wrap Cómo se ajusta el texto (soft, hard) wrap="hard"
autofocus El campo obtiene foco al cargar autofocus
