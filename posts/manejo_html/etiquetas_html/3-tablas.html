3. Elementos de Tabla

<table>

La etiqueta <table> define una tabla en HTML. Es el contenedor principal que agrupa filas y celdas. 

<table border="1">
  <tr>
    <th>Nombre</th>
  </tr>
  <tr>
    <td>Ana</td>
  </tr>
</table>
Atributo Descripción Ejemplo
border Ancho del borde de la tabla border="1"
cellpadding Espacio interior de las celdas cellpadding="8"
cellspacing Espacio entre celdas cellspacing="0"

<tr>

La etiqueta <tr> define una fila dentro de una tabla. 

<tr>
  <td>Celda 1</td>
  <td>Celda 2</td>
</tr>

<td>

La etiqueta <td> define una celda de datos dentro de una fila de tabla. 

<td colspan="2">Celda que ocupa 2 columnas</td>
Atributo Descripción Ejemplo
colspan Número de columnas que ocupa la celda colspan="2"
rowspan Número de filas que ocupa la celda rowspan="2"

<th>

La etiqueta <th> define una celda de encabezado dentro de una fila de tabla. El texto dentro de esta etiqueta se muestra en negrita y centrado por defecto. 

<th colspan="2">Encabezado que ocupa 2 columnas</th>

Los atributos son los mismos que para <td>: colspan y rowspan.
