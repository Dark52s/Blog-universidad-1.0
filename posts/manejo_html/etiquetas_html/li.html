<li>

La etiqueta <li> define un elemento de lista. 

<li value="10">Décimo elemento</li>

Esta etiqueta acepta atributos específicos.

Atributo Descripción Ejemplo
value Número ordinal del elemento (en ol) value="10"
type Tipo de viñeta (en ul): disc, circle, square type="square"
