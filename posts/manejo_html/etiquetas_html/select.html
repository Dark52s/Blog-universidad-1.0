<select>

La etiqueta <select> define un desplegable (lista de opciones). 

<select name="pais">
  <option value="ve">Venezuela</option>
  <option value="co" selected>Colombia</option>
</select>

Esta etiqueta acepta atributos específicos.

Atributo Descripción Ejemplo
name Nombre del select para el envío name="pais"
multiple Permite seleccionar múltiples opciones multiple
size Número de opciones visibles size="3"
required Selección obligatoria required
disabled Desactiva el select disabled
autofocus El select obtiene foco al cargar autofocus
form Asocia el select con un formulario form="miFormulario"
