<iframe>

La etiqueta <iframe> embebe una página HTML externa dentro de la actual. 

<iframe src="https://example.com" width="500" height="300" allowfullscreen></iframe>

Esta etiqueta acepta atributos específicos.

Atributo Descripción Ejemplo
src URL de la página a embedir src="https://example.com"
width Ancho del iframe width="500"
height Alto del iframe height="300"
name Nombre del iframe name="miFrame"
frameborder Mostrar borde (1 o 0) frameborder="0"
scrolling Barras de desplazamiento (yes, no, auto) scrolling="auto"
allowfullscreen Permite pantalla completa allowfullscreen
sandbox Restringe funcionalidades del contenido (allow-forms, allow-scripts, etc.) sandbox="allow-scripts"
loading Carga diferida (lazy, eager) loading="lazy"
