Formularios

Evaluación: Paradigmas de programación

1. En la arquitectura cliente-servidor, el cliente siempre inicia la comunicación.

2. El servidor no necesita estar conectado a internet para funcionar.

3. La arquitectura de 3 capas incluye: Presentación, Negocio y Datos.

4. Los DNS traducen direcciones IP a nombres de dominio legibles.

5. El protocolo HTTP es un ejemplo de protocolo de comunicación.

Evaluación: Manejo de HTML

1. Las etiquetas HTML siempre necesitan etiqueta de apertura y cierre.

2. La etiqueta <a> se utiliza mas para enalces externos y <link> para enlazar archivos internos como un stylesheet.

3. La etiqueta <table> no posee atributos propios, solo acepta atributos globales.

4. La etiqeuta <li> se utiliza para crear filas en una tabla.

5. La etiqueta <!DOCTYPE html> a HTML 5 como la version del documento por predeterminado.

Evaluación: Manejo de CSS

1. CSS significa Cascading Style Sheets.

2. Las clases en CSS se definen con un punto.

3. El padding es el espacio fuera del borde de un elemento.

4. La pseudo-clase :hover se aplica cuando el ratón está sobre el elemento.

5. La propiedad display define el tipo de caja de un elemento.

Evaluación: Manejo de JavaScript

1. Las variables declaradas con `let` tienen un alcance de bloque.

2. Una variable declarada con `const` puede ser reasignada con un nuevo valor más adelante.

3. El ciclo `do-while` evalúa su condición al final, asegurando que el código se ejecute al menos una vez.

4. Las funciones flecha utilizan el operador `=>` para reducir su sintaxis.

5. Para enlazar un archivo externo de JavaScript se utiliza la etiqueta `<link>`.
