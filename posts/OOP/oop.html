Programación Orientada a Objetos (OOP)

Introducción

La progrmación orientada a objetos es un paradigma de programación donde todo es un objeto con atributos y metodos. Los objetos son equivalentes a los que existen en la vida real, por ejemplo: Un gato tiene atributos como un color, un tamaño o un peso, ademas el gato puede caminar, saltar, maullar todos estos son equivalentes a los metodos. OOP cambio por completo el desarrollo de software desde su llegada con Java y C++ hasta el dia de hoy que es uno de los pilares de la programación por lo que a continuación enseñaremos como se aplica en JavaScrpit

Objetos o Instancias

Los objetos son equivalentes a los que existen en la vida real, por ejemplo: Un gato tiene un color, un peso y un tamaño, estos son sus atributos, ademas, un gato puede caminar, saltar o maullar, estas son acciones que le permite interactuar con el mundo, asi mismo funcionan los objetos en OOP, estos tienen sus atributos y acciones que pueden realizar, a estas ultimas se le conocen como metodos. Los objetos tambien se le conocen como instancias de una clase, esto se refiere a la creación o instanciación de un nuevo objeto.

Clases

Las clases se podrian definir como el molde para un objeto, se crean utilizando para la palabra reservada class y en este podemos determinar los atributos y metodos que tendra nuestros objetos.

Ejemplo de clase en JavaScript

class Persona {

    // Metodo constructor
    constructor(nombre, edad) {

        // Atributos
        this.nombre = nombre;
        this.edad = edad;
    }

    // Metodo
    saludar() {
        return "Hola, soy ${this.nombre} y tengo ${this.edad} años";
    }
}

En este ejemplo creamos una clase Persona utilizando la palabra clave class ademas de eso creamos un constructor con el cual creamos dos atributos, nombre y edad, fuera del constructor se crea un metodo saludar() que retorna una cadena. A continuación se explicara que es un constructor y para que se utiliza this.

Constructor

Un constructor es un metodo que nos permite instanciar una clase donde queramos. Para que un metodo sea constructor se tiene que llamar así si o si, un constructor puede pedir argumentos y ejecutar un bloque de codigo como cualquier metodo.

this

La palabra clave this se refiere al contexto en el que se deberia ejecutar una pieza de codigo. Se suele utilizar para referirse al objeto o clase al que pertenece un metodo como en el ejemplo anterior donde this pasa a referirse a la clase Persona.

El valor de this depepnde de como ha invocado una función, si el metodo se creo dentro de un objeto this equivaldrá al objeto, pero si se invoca una función no atada a un objeto se referirá a el Global Object (El contexto mas amplio posible donde encuentran los objetos que estan disponibles en cualquier contexto).

Instanciando una clase

const juan = new Persona("Juan", 20);
console.log(juan.saludar());

La instancia de nuestra clase la almacenamos en un objeto que llamamos juan, ahora, utilizamos la palabra clave new (Esta keyword se utiliza para instanciar una clase mediante un constructor) seguida del constructor a quien le pasamos los argumentos solicitados y ahora mediante el objeto juan podemos usar el metodo saludar() de la clase Persona.

Herencia

Es una de las caracteristicas mas importantes de OOP que nos permite hederar los metodos y atributos de una clase padre a una clase hija. 

// Clase padre
class Videojuego {
    constructor() {}

    comprar() {
        console.log("Compra exitosa");
    }
}

// Clase hija
class Minecraft extends Videojuego {
}

const mc = new Minecraft();

// Hedera el metodo comprar()
console.log(mc.comprar());

En este ejemplo la clase Videojuego se convierte en la clase padre de la clase Minecraft y le hereda el metodo comprar() que ahora puede ser utilizada por el objeto mc.

Polimorfismo

Es la habilidad que tiene el mismo metodo de realizar dos acciones distintas dependiendo de la clase o contexto en el que se encuentre.

class Animal {
    habla() {
        console.log("Animal hace un sonido");
    }
}

class Perro extends Animal {
    habla() {
        console.log("Perro ladra");
    }
}

let animal = new Animal();
let perro = new Perro();
perro.habla(); // Animal hace sonido
animal.habla(); // Perro ladra

En este ejemplo el metodo habla() es cambiada por la clase Perro para que imprima un texto diferente.

Abstracción

Abstracción significa modelar un objeto quedándote solo con las características esenciales para el problema que resuelves, ignorando los detalles irrelevantes. Es la misma idea que usamos en la vida real: cuando piensas en un "auto", no piensas en cada tornillo, cable o pistón del motor. Piensas en "algo que tiene volante, acelera, frena y te lleva de un lugar a otro". Esa simplificación mental es abstracción.

Basicamente, no se especifica que hace un metodo, solo creas el metodo como un molde para que las clases hijas hagan lo que quieran con ese metodo. En JavaScript no existe manera de hacer clases abstractas (clases padre que son moldes para clases hijas, pero se puede imitar.

class Animal {
    // Metodo que no realiza nada
    hacerSonido() {}
}

class Perro extends Animal {
    hacerSonido() {
        console.log("Guau");
    }
}

class Gato extends Animal {
    hacerSonido() {
        console.log("Miau");
    }
}

let perro = new Perro();
let gato = new Gato();

// El mismo metodo imprimen texto distinto
gato.hacerSonido();
perro.hacerSonido();

En este ejemplo en la clase Animal no se especifica como funciona el metodo hacerSonido() es un molde para que la clase Perro y Gato la utilicen como quieran, aqui tambien se aplica el polimorfismo, utilizando la misma funcion para imprimir un texto distinto.

Encapsulamiento

Consiste en diferentes niveles de acceso que se les pueden asignar a las propiedades y metodos de una clase, en los lenguajes de programación orientada a objetos más clasicos existen las palabras clave private, public y protected.

En JavaScript no existen estas palabras claves, incluso no existe un equivalente para protected, (Accesible desde la propia clase y desde cualquier clase que herede de ella (subclases), pero no desde fuera de esa jerarquía de clases), cuando creas un metodo o atributo es publico por defecto, para convertirlos en privados sebe utilizar la almoadilla (#).

class Cafetera {
    hacerCafe() {
        this.#hecharAgua();
        this.#prepararCafe();
        this.#tiempoPreparacion = 3;

        console.log("Coffee is ready!");
    }

    #hecharAgua() {
        console.log("Boiling water...");
    }

    #prepararCafe() {
        console.log("Brewing coffee...");
    }
}

const cafe = new Cafetera();
cafe.hacerCafe();

En este ejemplo se utiliza la almoadilla seguida de los metodos hecharAgua() y prepararCafe(), ademas, de el atributo tiempoPreparacionpara hacerlas privada, si se intenta utilizar fuera de la clase el interprete dará error.

JavaScript es un lenguaje basado en prototipos

Aunque JavaScript existen las clases no es un lenguaje de programación orientado a objetos a raja tabla como si lo es Java por ejemplo. En C++, Pyhtoh o C# la diferencia entre clase e instancia esta marcada mientras que en JavaScirpt a pesar de que existe la palabra clave class estos tambien son objetos.

Los objetos tambien pueden hederar sus propiedades a otro objeto, en ese caso se les llaman prototipos. Todo objeto en javascript tiene una referencia interna a su prototipo. Cuando accedes a una propiedad que el objeto no tiene, javascript la busca automáticamente en su prototipo, y si tampoco está ahí, sube al prototipo del prototipo... y así sucesivamente. Esto se llama cadena de prototipos (prototype chain).

const animal = {
  respirar() {
    return "Respirando...";
  }
};

const perro = {
  ladrar() {
    return "Guau!";
  }
};

// conectamos perro -> animal
Object.setPrototypeOf(perro, animal);

perro.ladrar();   // "Guau!" (propiedad propia)
perro.respirar(); // "Respirando..." (heredada del prototipo)

En este ejemplo el objeto animal se convierte en el prototipo del objeto perro utilizando la función setPrototypeOf(prototipo, objeto) el prototipo le hedera el metodo respirar(). javascript en este caso primero intenta buscar en el objeto perro el metodo respirar() pero como no lo encuentra lo busca y consigue en su prototipo animal.
